# Chenguang Duan — homepage

This repository contains a single-page Jekyll site for GitHub Pages.

- Edit the biography, research interests, and publications in `index.md`.
- Edit the left profile column in `_layouts/default.html`.
- Edit the visual styling in `assets/css/style.scss`.
- Store papers and slides in `docs/`.

The layout intentionally stays close to GitHub Pages' original Minimal theme: a profile column on the left and one plain content column on the right.
